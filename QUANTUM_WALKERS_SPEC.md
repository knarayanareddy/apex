## 1. Principles & Non-Goals

### Principles

1. **Physics first:** Every circuit must be provable via `Statevector` or `Operator`; sampling is a *view*, not truth.
2. **One invariant per test:** A failing test names the broken law (parity, unitarity, binomial, etc.), not "something changed".
3. **Deterministic CI:** Seeded simulator runs; no flaky tests >0.1% at 95% confidence.
4. **Backwards compat:** `import hadamard_demo` and `import coined_walk` keep working (shims).
5. **No magic numbers in logic:** Constants (`POSITION_QUBITS`, `SHOTS`, `START`) live in one place and are importable.
6. **Docs as code:** README, docstrings, and notebooks are tested (doctest / `nbval` smoke).

### Non-Goals (explicitly out of scope for v1)

- Continuous-time or Szegedy walks (tracked in `ROADMAP.md`).
- Real IBM hardware execution in CI (requires secrets; we provide a *manual* hardware script behind an env guard).
- Full QEC / error mitigation library — we only add depolarizing + readout noise models.

## 10. Phase 7 — Test Strategy & Coverage Gates

### Pyramid

```
Unit (fast, <0.1s each)          — increment, coins, spread, classical
Integration (medium, <2s)        — coined_walk + exact vs sampled
E2E / Snapshot (slow, <6s)       — plot PNG, total suite <15s on CI
Property (optional)               — hypothesis: parity holds ∀ steps≤15
```

### Tooling

- `pytest` + `pytest-cov` + `pytest-xdist` (optional) with `addopts = -q --strict-markers --cov=quantum_walkers --cov-report=term-missing --cov-fail-under=85`
- Thresholds:

| Metric | Gate |
|--------|------|
| Line coverage | ≥85% (fail under) |
| Branch coverage | ≥80% |
| Flaky rate | 0 failed reruns in 3× `pytest --reruns 3` locally |
| Suite time | <20s on `ubuntu-latest` |

### What "extensive" means here

- ≥50 tests (current 15 → +35)
- Every `raise ValueError` has a `pytest.raises(..., match=...)` test
- Every public function has ≥2 tests (happy + edge)
- Parametrized over `n`, `steps`, `coin_state`, `shots`
- One golden snapshot per `exact_distribution(t)` for `t in [0,1,3,5,10,15]` (regression lock)

**Rubric (Phase 7):**

- [ ] `pytest --cov` reports ≥85% line
- [ ] `pytest -q` passes 3 consecutive runs without flake
- [ ] No test imports `matplotlib` at top level (lazy import inside function — keeps CI fast)
- [ ] Tests do not write to repo root (use `tmp_path`)

## 15. Risk Register & Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Qiskit 3.x breaks `transpile`/`mcx` API | M | High | Pin `qiskit>=2.6,<3` in `pyproject.toml`; have `Operator` fallback test |
| `mcx` needs ancillas for n≥5 (inc. 5→4 controls) | M | M | Test unitary for n up to 6; if fails, add `ancilla` register or use `qiskit.circuit.library.IncrementGate` alternative |
| Flaky sampler test (TVD <0.03) | L | M | Seed=1, 20k shots → 6σ margin; mark `flaky` with rerun |
| PNG non-determinism (font) | M | L | `matplotlib.use("Agg")`, fixed `dpi=150`, `tight_layout`, no system font |
| Hardware token leak | L | High | `.gitignore` + `detect-secrets`; hardware script requires env var, never commits token |
| Scope creep (2-D, Szegedy) delays ship | H | M | Gate Phase 5 behind `ROADMAP.md`; ship v0.1.0 without it |
